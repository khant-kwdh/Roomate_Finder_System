# 🏠 Roommate Finder System
The **Roommate Finder System** is a web-based application designed to help students and individuals find suitable roommates according to their personal information, preferences, lifestyle, and accommodation requirements.

The system provides a convenient platform where users can create profiles, search for potential roommates, connect with other users, and communicate with them.

An administrator can also manage registered users, verify accounts, and handle user complaints.

## Features

### 👤 User Features
- User Registration and Login
- User Profile Management
- Personal Information and Preference Management
- Find Suitable Roommates
- Search and Filter Roommates
- Connect with Other Users
- View Connections
- Messaging and Communication
- Submit Complaints
- Contact and FAQ Pages

### 🛡️ Admin Features
- Admin Login
- Admin Dashboard
- Verify and Approve Users
- Reject User Registrations
- Manage Registered Users
- Manage and Resolve Complaints

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript, JSP
- **Backend:** Java, Java Servlets
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Development Environment:** Eclipse IDE
- **Web Server:** Apache Tomcat

## Database

The application uses MySQL to store and manage user information, roommate preferences, connections, messages, and complaints.

## Installation and Setup

1. Clone or download this repository.
2. Import the project into Eclipse IDE as a Dynamic Web Project.
3. Install and configure Apache Tomcat.
4. Install MySQL and create the required database.
5. Configure the database connection in `DBConnection.java`.
6. Add the MySQL Connector/J library.
7. Configure the project server runtime.
8. Run the project on Apache Tomcat.

## Project Purpose

The main purpose of this project is to simplify the roommate searching process by providing a centralized platform where users can discover, connect, and communicate with potential roommates based on their preferences.
